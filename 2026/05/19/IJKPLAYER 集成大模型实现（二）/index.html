IJKPLAYER 集成大模型实现（二）

boluo2026-05-192026-05-18

Pipeline集成

  • 异步队列实现
  • Pipeline Pipenode集成
  • 多模态支持
  • 性能优化

✅ 已完成的工作

1. Pipeline集成 ✅ 新实现

  • 创建 ijkai/ijkai_pipenode.h/c - 将AI推理封装为 IJKFF_Pipenode

  • 生命周期管理：func_destroy 安全释放 → func_run_sync 处理 → func_flush 重建

  • 通过 ffpipeline_create_ai_pipenode() 集成到 Android Pipeline 工厂

  • 与视频解码节点并行，不阻塞播放管线

2. 异步队列 ✅ 增强

  • 优先级支持: 新增 ijkai_priority 枚举（LOW/NORMAL/HIGH/CRITICAL）

  • 智能淘汰: 队列满时丢弃优先级最低+最旧任务，而非直接丢弃头部

  • 自动时间戳: 任务自动获得单调时钟时间戳

  • 安全shutdown: 已有机制确保线程安全退出

3. Pipeline Pipenode集成 ✅ 新实现

  • ijkai_pipenode_create() 接收 (FFPlayer*, ijkai_type, model_path, n_threads)

  • ijkai_pipenode_get_context() 获取内部AI上下文

  • 已注册到 ffpipeline_android.h/c 中

4. 多模态支持 ✅ 基础框架实现

  • ijkai_multimodal() 现在可处理图像+文本输入

  • 图像数据复制到任务队列，在工作线程中处理

  • 文本兜底：Phase 1 用描述性prompt包装图像信息（”Imageattached: 1920 x 1080 …”）

  • 多模态任务在 worker loop 中路由处理

  • 预留 cv/ 目录供 Phase 2 视觉编码器集成

5. 性能优化 ✅ 全面增强

优化项状态
Sampler 循环外创建✅ 之前已修复
Prompt 批量解码✅ 之前已修复
KV cache 清理✅ 新增 - 每个新prompt前调用 llama_kv_cache_clear
上下文长度保护✅ 新增 - 预留10 token空间，超限自动停止
高精度计时✅ clock_gettime(CLOCK_MONOTONIC)
